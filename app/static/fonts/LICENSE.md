# Fonts

Subsets of two fonts from Google Fonts, cut down to Latin and the axes the app uses with fontTools
(`varLib.instancer`, then `pyftsubset`). Archivo keeps wdth 72–100 and wght 400–600; Newsreader is a static
instance at opsz 24, weight 500. Each comes as a core file (ASCII and the punctuation the app uses) and an
`-ext` file with the rest of Latin-1, split by `unicode-range`.
